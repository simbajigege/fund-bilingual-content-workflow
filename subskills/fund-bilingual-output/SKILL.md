# Fund Bilingual Output

## Overview

把中文草稿打磨为中英文两版成稿，保持数据一致、表达适配不同读者。

## Required Method

1. 中文版：
- 保留本土表达和可选A股/港股类比
- 可读性优先，强调“认知框架+行动建议”
2. 英文版：
- 独立重写标题，不做直译
- 删除所有中国市场类比
- 使用专业英文投资写作风格

## Output Format

输出两个 Markdown 文件内容：
- `*_zh.md`
- `*_en.md`

并附“差异核对清单”：
- 英文版无中国市场标的
- 核心数据与图表引用一致
- 风险提示与免责声明完整
