# Fund Topic Planning

## Overview

读取主流程提供的 `workflow_context.json`（或等价上下文），根据 v3 规则输出候选选题、评分矩阵和首发建议。
本技能仅定义模型思路与输出格式，不使用脚本自动写文案。

## Inputs

- 三类分析结果（热力图、堆叠图、双轴图）
- 基金/大师标识与时间范围
- 可选：当前热点事件关键词

## Required Method

1. 从信号清单提取异常点：
- 大仓位+看空
- 小仓位+看多
- 连续加减仓
- 双轴斜率差异常
2. 映射到选题类型：
- 分歧冲突型、行为模式型、时机选择型、热点嫁接型等
3. 逐题打分（1-5）：
- 流量潜力、数据支撑、时效性、受众匹配、易学性
4. 选择：
- 满足 >=2 维保留，>=3 维优先，>=4 维首发

## Output Format

输出 Markdown，包含：
- 候选选题表（标题、类型、核心证据、五维评分、总分）
- 首发选题（Top 1-3）与发布顺序建议
- 每个首发题的“反常识开场句”（1句）

## Constraints

- 不输出投资建议结论性语句，必须包含“仅供参考”风险提示。
- 不得跳过评分步骤，不得只给单个题目。
