# 内容生产指南

本文档说明如何将基金持仓分析结果用于投资博客内容生产工作流。

## 1. 工作流概述

### 完整内容生产流程

```
数据获取 → 分析解读 → 选题策划 → 深度调研 → 内容写作 → 双语输出 → 质量检查
```

### 与本技能的集成点

1. **数据获取**：使用本技能获取并分析基金持仓数据
2. **分析解读**：基于分析结果提取关键信号和投资启示
3. **选题策划**：根据信号类型生成选题矩阵
4. **深度调研**：为重点股票提供调研方向和要点

## 2. 分析结果到内容的映射

### 2.1 热力图信号 → 博客选题

| 信号类型 | 选题角度 | 内容重点 | 目标读者 |
|---------|---------|---------|---------|
| **大色块+绿色** | "抄作业"的最佳选择 | 重仓逻辑+AI看好原因分析 | 跟随型投资者 |
| **大色块+红色** | 最具争议的投资分歧 | 大师与AI的逻辑冲突分析 | 价值发现型投资者 |
| **小色块+绿色** | 潜力股的早期发现 | 轻仓原因+未来增仓可能性 | 成长型投资者 |
| **整体颜色偏红** | 风险警示专题 | 整体高估值原因+调整预期 | 风险规避型投资者 |

### 2.2 财务指标 → 分析维度

| 指标类型 | 分析角度 | 内容模块 |
|---------|---------|---------|
| **估值指标** | 估值合理性分析 | "估值洼地"或"估值陷阱" |
| **动量指标** | 价格趋势分析 | "强势股"或"超跌股" |
| **流动性指标** | 市场关注度分析 | "机构宠儿"或"冷门股" |

### 2.3 AI建议 → 投资逻辑

| AI建议类型 | 解读角度 | 内容价值 |
|-----------|---------|---------|
| **高置信度建议** | AI的确定性判断 | 提供较强的参考依据 |
| **目标价空间大** | 上涨潜力分析 | 吸引读者关注的关键点 |
| **风险评分低** | 安全性分析 | 风险控制的重要内容 |

## 3. 博客结构设计（7段式）

### 3.1 标准结构模板

```
# [标题]：{基金名称}持仓分析：{关键发现}的投资启示

## 1. 开篇：热力图全景一览
- 插入持仓热力图截图
- 说明色块大小和颜色含义
- 提供跳转链接到实时数据

## 2. 关键信号解读：大师与AI的共识与分歧
- 共识点分析（重仓+AI看好）
- 分歧点分析（重仓但AI看空）
- 投资启示

## 3. 财务指标深度分析
- 估值水平分析（PE/PB）
- 价格动量分析（涨幅/振幅）
- 流动性分析（换手率/成交量）

## 4. AI投资建议汇总
- 操作建议分布统计
- 置信度与风险评估
- 目标价空间分析

## 5. 行业分布与赛道选择
- 行业集中度分析
- 细分龙头公司点评
- 行业趋势判断

## 6. 综合评估与风险评估
- 组合综合评分解读
- 优势与不足分析
- 关键风险提示

## 7. 投资建议与行动指南
- 重点关注股票列表
- 适合的投资者类型
- 后续跟踪要点

## 附录：数据与方法
- 数据来源说明
- 分析方法简介
- 免责声明
```

### 3.2 各章节内容填充指南

#### 章节1：开篇
- **截图选择**：选择最能体现关键信号的热力图区域
- **说明文字**：简要说明色块大小=权重，颜色=AI评级
- **读者引导**：提供工具页面的跳转链接

#### 章节2：关键信号解读
- **共识点**：分析为什么这些股票同时获得重仓和AI看好
- **分歧点**：探讨大师重仓逻辑与AI看空原因的冲突
- **故事性**：将分歧点作为博客的"钩子"，吸引读者阅读

#### 章节3：财务指标分析
- **数据可视化**：使用简单的表格或图表展示关键指标
- **对比分析**：与行业平均、历史水平对比
- **重点突出**：只分析最有代表性的2-3个指标

#### 章节4：AI投资建议
- **统计可视化**：使用饼图展示操作建议分布
- **置信度解读**：说明AI判断的可靠程度
- **目标价分析**：计算上涨空间，找出潜力最大的股票

#### 章节5：行业分布
- **赛道分析**：分析大师重点布局的行业逻辑
- **龙头点评**：简要点评行业内的代表性公司
- **趋势判断**：基于行业配置判断大师的投资偏好

#### 章节6：综合评估
- **评分解读**：用通俗语言解释评分含义
- **优劣势分析**：客观分析持仓的亮点和不足
- **风险提示**：明确提示需要关注的风险点

#### 章节7：投资建议
- **行动指南**：提供具体的操作建议
- **读者分层**：针对不同投资者类型给出不同建议
- **跟踪要点**：列出后续需要关注的关键点

## 4. 标题生成策略

### 4.1 标题模板库

#### 共识型标题（大色块+绿色）
- `抄作业时间到！{基金}重仓{股票}，AI也看好`
- `{基金}的"压舱石"：{股票}为何获重仓+AI双重认可`
- `大师与AI的共识：{基金}重点布局{行业}龙头`

#### 分歧型标题（大色块+红色）
- `投资分歧！{基金}重仓{股票}，AI却亮红灯`
- `{基金}的争议持仓：{股票}的重仓逻辑与AI看空原因`
- `大师与AI的博弈：{股票}到底值不值得买？`

#### 潜力型标题（小色块+绿色）
- `{基金}的"潜力股"：轻仓的{股票}获AI强烈看好`
- `悄悄建仓？{基金}轻仓布局{股票}，AI评级"买入"`
- `下一个重仓股？{基金}试探性买入{股票}`

#### 风险型标题（整体偏红）
- `警报！{基金}持仓AI评级大面积飘红`
- `{基金}的"红色预警"：{比例}%持仓被AI看空`
- `谨慎抄作业：{基金}持仓整体估值偏高`

### 4.2 标题优化技巧

1. **数字吸引**：在标题中加入具体数字
   - `3只重仓股获AI"买入"评级`
   - `上涨空间30%！{股票}目标价分析`

2. **情绪共鸣**：使用读者有共鸣的词汇
   - `抄作业`、`压舱石`、`警报`、`博弈`

3. **问题引导**：使用问句引发思考
   - `{股票}到底值不值得买？`
   - `为什么AI不看好{基金}的重仓股？`

4. **趋势暗示**：暗示投资机会或风险
   - `下一个爆发点`、`潜在风险`、`被低估`

## 5. 内容深度控制

### 5.1 内容深度层级

#### Level 1：基础解读（适合大众读者）
- 关键信号简单说明
- 基本财务指标解释
- 简单的投资建议

#### Level 2：专业分析（适合投资爱好者）
- 详细的财务指标分析
- 行业深度解读
- 风险收益分析

#### Level 3：深度研究（适合专业投资者）
- 个股基本面分析
- 估值模型构建
- 投资策略设计

### 5.2 根据信号重要性分配篇幅

| 信号优先级 | 篇幅占比 | 内容深度 |
|-----------|---------|---------|
| **P0：大色块+红色** | 30-40% | 深度分析，包括逻辑冲突、投资启示 |
| **P1：大色块+绿色** | 25-35% | 详细分析，包括重仓逻辑、AI看好原因 |
| **P2：高上涨潜力** | 15-25% | 适度分析，包括目标价空间、催化剂 |
| **P3：其他信号** | 10-20% | 简要提及，作为背景信息 |

## 6. 可视化建议

### 6.1 图表类型选择

| 数据类型 | 推荐图表 | 使用场景 |
|---------|---------|---------|
| **权重分布** | 热力图 | 开篇全景展示 |
| **AI评级分布** | 饼图/柱状图 | AI建议汇总章节 |
| **财务指标对比** | 表格/雷达图 | 财务分析章节 |
| **行业分布** | 旭日图/树图 | 行业分析章节 |
| **价格走势** | 折线图 | 个股分析（如需） |

### 6.2 截图规范

1. **热力图截图**：
   - 截取完整的热力图区域
   - 包含图例说明
   - 标注关键信号位置

2. **工具界面截图**：
   - 包含基金代码和名称
   - 显示关键数据区域
   - 保持界面整洁

3. **数据表格截图**：
   - 突出关键数据
   - 使用颜色标注重要信息
   - 保持可读性

## 7. 双语输出策略

### 7.1 中文版特点
- **市场类比**：可与A股其他基金或股票对比
- **政策关联**：联系中国相关政策影响
- **文化语境**：使用中文投资圈常用术语
- **本地案例**：引用中国市场的典型案例

### 7.2 英文版特点
- **国际视角**：与国际市场对比
- **通用术语**：使用国际通用的投资术语
- **去本地化**：移除中国特有的政策和文化引用
- **全球可比**：使用全球通用的估值和比较方法

### 7.3 翻译注意事项

1. **术语统一**：建立中英文术语对照表
2. **文化适配**：调整案例和比喻以适应目标读者
3. **数据格式**：调整货币单位、日期格式等
4. **法律合规**：确保符合目标市场的法规要求

## 11. 工具集成示例

### 11.1 命令行工具使用

```bash
# 生成分析报告
python scripts/fetch_and_analyze.py --fund-code 159730 --output-dir ./reports

# 查看分析结果
cat ./reports/summary_159730.txt

# 生成博客大纲
python scripts/generate_outline.py --analysis ./reports/analysis_159730.json --template blog_template.md
```

### 11.2 Python API使用

```python
from fund_analyzer import FundHeatmapAnalyzer

# 初始化分析器
analyzer = FundHeatmapAnalyzer()

# 获取并分析数据
report = analyzer.analyze_fund("159730")

# 生成博客内容
blog_content = analyzer.generate_blog_content(
    report,
    template="7_segment",
    target_audience="retail_investors"
)

# 保存结果
report.save_json("./reports/analysis_159730.json")
blog_content.save("./blogs/fund_159730_analysis.md")
```
